掃描指定圖案啟動 AR

用 Chrome 或 Safari 對準紙雕小狗圖案，影片會鎖在圖案上並跟著移動。

請改用 Chrome 或 Safari 開啟

WhatsApp、Line、IG 內建瀏覽器通常不允許使用相機，所以 AR 無法啟動。這不是連結壞掉。

用 Chrome 開啟

iPhone：點右上角「⋯」→ 選擇「在 Safari 開啟」。

怎麼掃
  1. 用電腦或平板全螢幕打開「只顯示圖案」。
  2. 手機用 Chrome 或 Safari 點「開始掃描」，允許相機。
  3. 對準整張紙雕小狗圖。
開始掃描 只顯示圖案（給另一台螢幕）
